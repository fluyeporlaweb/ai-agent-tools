# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security problem. Use GitHub private vulnerability reporting in [fluyeporlaweb/agent-tools](https://github.com/fluyeporlaweb/agent-tools/security/advisories/new). If that option is not available, contact the maintainers through [fluyeporlaweb.com](https://fluyeporlaweb.com) and include enough detail to reproduce the issue.

Please include the affected tool, the version or commit, the impact, and the steps to reproduce it. We aim to acknowledge reports within 7 days. There is no bug bounty program.

Only the latest published version of each tool is supported.
